Easy Context · 安装说明
==============================

Easy Context 给「访达（Finder）」的右键菜单增加：复制完整/相对路径、
用终端或编辑器打开当前目录、新建文件等。

⚠️ 本应用未做 Apple 公证，首次打开安装包需手动允许一次（之后就正常）。
请根据 Mac 芯片选择 Release 安装包：Apple Silicon 下载 `EasyContext-<版本>-macOS-arm64.pkg`，Intel 下载 `EasyContext-<版本>-macOS-x86_64.pkg`。
请按下面 4 步操作：

1) 打开安装包
   右键点已下载的架构对应 `.pkg` →「打开」→ 在弹出的窗口里再点一次「打开」。
   （直接双击会被系统拦下，务必用右键打开这一次；之后的更新同理。）

2) 完成安装
   按安装向导点「继续 / 安装」，按提示输入开机密码授权装到「应用程序」。
   安装程序会自动关闭正在运行的旧版本、装完自动重启 EasyContext——
   所以重装 / 更新时你不用手动退出 App，也不会再遇到“正在使用中”。

3) 启用访达扩展（关键，必做）
   打开 EasyContext，顶部若有橙色提示，点「去启用」；或手动到
   系统设置 → 通用 → 登录项与扩展 → 访达扩展 → 勾选 “EasyContextFinder”。

4) 开始使用
   在访达里右键任意文件或文件夹，即可看到 Easy Context 的菜单项。

------------------------------------------------------------
· 无需再执行 xattr 清理命令：pkg 装出来的 App 不带隔离标记（quarantine）。
· 命令行安装（进阶）：sudo installer -pkg EasyContext-<版本>-macOS-arm64.pkg -target /
  Intel 用户请将文件名中的 arm64 替换为 x86_64。
· Release 同时提供 arm64 与 x86_64 两个独立包，并分别提供 SHA-256 校验文件。
· 源码构建：TARGET_ARCH=arm64 ./scripts/build-pkg.sh（版本统一读取 project.yml）。
  Intel 使用 TARGET_ARCH=x86_64；省略 TARGET_ARCH 仍可本地构建 universal 包。
  修改代码后重新安装测试，请先用 ./scripts/prepare-release.sh --build-only 增加构建号；
  如果产品版本低于已安装版本，请先准备更高版本，详见 README 的发布流程。
· 设置：打开 EasyContext 可配置显示哪些终端/编辑器、菜单图标黑白或彩色等。
· 更新：点击设置窗口底部版本号旁的刷新图标，以弹窗查看检查结果。
  有新版时可点击「前往 GitHub 下载」；不自动检查、下载或安装。
· 配置文件：~/.easy-context/config.json（高级用户可手改）。
· 卸载：把「应用程序」里的 EasyContext 拖到废纸篓即可。
